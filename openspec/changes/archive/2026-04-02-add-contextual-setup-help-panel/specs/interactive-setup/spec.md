## 新增需求

### 需求:设置界面必须为当前交互状态显示上下文化帮助栏
设置界面必须在帮助栏中显示与当前高亮项或当前交互状态对应的说明文本，并且必须在单独一行显示该状态下可用的快捷键；禁止只显示固定通用提示，或在状态切换后继续显示不适用的快捷键。

#### 场景:根菜单选中通用设置时显示当前项帮助
- **当** 用户位于设置界面的根菜单，并将光标停留在 `通用设置`
- **那么** 帮助栏第一行必须说明 `通用设置` 用于配置语言、功能开关等通用项目
- **并且** 帮助栏第二行必须列出当前可用快捷键，至少包含保存、退出、上下选择和进入子菜单

#### 场景:文本编辑态覆盖普通菜单帮助
- **当** 用户在任意文本字段上按 Enter 进入编辑器
- **那么** 帮助栏必须切换为编辑态说明和编辑快捷键
- **并且** 帮助栏不得继续显示普通菜单态的“进入子菜单”或“空格切换”提示

#### 场景:退出确认态覆盖普通菜单帮助
- **当** 用户存在未保存修改并触发退出确认
- **那么** 帮助栏必须说明当前正在确认退出方式
- **并且** 帮助栏必须只显示确认态可用的上下选择、确认和取消快捷键

### 需求:帮助栏必须保留可见正文区域
设置界面布局必须为帮助栏保留足够的正文高度，使帮助栏在常见终端尺寸下至少能够同时显示一行说明和一行快捷键；禁止只渲染边框而看不到帮助正文。

#### 场景:默认 setup 界面可见显示两行帮助正文
- **当** 用户在常见终端尺寸下打开 `xgit setup`
- **那么** 帮助栏必须能实际显示说明行和快捷键行
- **并且** 用户不得只能看到一个空白的帮助边框
