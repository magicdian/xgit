## 新增需求

### 需求:设置界面必须说明注释模板与旧代码处理的依赖关系
设置界面必须在 `修改格式`、`删除格式` 和 `旧代码处理` 相关帮助内容中明确说明各自的生效条件与依赖关系，禁止只展示菜单名称而不解释哪些组合会真正影响 annotate 结果。

#### 场景:查看修改格式帮助时看到旧代码关闭后的行为
- **当** 用户在 setup 中选中 `修改格式`
- **并且** 旧代码处理当前处于关闭状态
- **那么** 帮助栏必须明确说明修改注释仍可生效
- **并且** 帮助栏必须明确说明不会输出 `old` 字段或旧代码内容

#### 场景:查看删除格式帮助时看到旧代码依赖
- **当** 用户在 setup 中选中 `删除格式`
- **那么** 帮助栏必须明确说明删除格式依赖旧代码处理
- **并且** 帮助栏必须明确指出只有删除格式与旧代码处理同时开启时删除块格式化才会生效

#### 场景:查看旧代码处理帮助时看到其不会替代模板开关
- **当** 用户在 setup 中选中 `旧代码处理`
- **那么** 帮助栏必须明确说明它只控制旧代码展示
- **并且** 帮助栏必须明确说明它不会自动开启 `修改格式` 或 `删除格式`
